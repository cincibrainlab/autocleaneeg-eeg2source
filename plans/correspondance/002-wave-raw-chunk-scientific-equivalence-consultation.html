Specialist Response

Reference oracle and numerical tolerance

Use one deterministic, preloaded, representative Raw fixture after the same channel picking, montage, resampling, and average-reference projection steps. Build the forward solution, ad-hoc covariance, and inverse operator once. With the same object state, compute (A) one whole-recording apply_inverse_raw followed once by DK extract_label_time_course, and (B) sequential half-open chunks, each immediately reduced with the same labels/source space and concatenated along time. Compare the in-memory float64 label arrays before EEGLAB export, because file serialization can introduce a separate precision/metadata effect.

The proposed acceptance oracle is: identical shape, label order, finite/non-finite mask, and sample order; then numpy.testing.assert_allclose(candidate, baseline, rtol=1e-10, atol=1e-15, equal_nan=True). Also report maximum absolute error and a scale-normalized maximum error max_abs_error / max(max(abs(baseline)), 1e-15). This is intentionally strict: MNE minimum-norm application and mean label reduction are linear, column-local operations under fixed inputs/settings, so changing only temporal batching should produce roundoff-level differences, not scientifically material drift. The absolute floor accommodates near-zero source values; the relative term guards larger values. If the strict oracle fails, do not loosen it merely to pass: first test the same BLAS/backend, dtype, prepared-inverse behavior, channel order, and boundary indexing. Any broader tolerance is a PI/Raven scientific decision requiring empirical error evidence across representative recordings.

Sample, time, and annotation alignment

  • Chunk intervals must partition processed Raw-relative samples exactly as [start, stop): first start 0, adjacent stop == next start, final stop raw.n_times, with no overlap, omission, duplicated boundary sample, padding, or resampling inside the inverse loop.
  • The concatenated label array must have exactly raw.n_times columns. Column j must correspond to processed Raw-relative sample j; sampling frequency and sample period must equal the baseline.
  • Baseline output currently constructs a new Raw with first_samp=0. Scientific equivalence therefore requires preserving that baseline convention unless the PI explicitly approves a contract change. Input first_samp/first_time should be recorded in the oracle even though the legacy output discards it.
  • Annotations require an explicit contract. Copying the input annotation object into a new first_samp=0 Raw is not automatically proven aligned, especially when input first_samp, first_time, or orig_time is nonzero. Verify each annotation's onset, duration, description, and time-base interpretation against the processed samples. If strict 0.3.7 output equivalence is the goal, note that the legacy converter did not attach annotations; adding them is a behavior extension and must be separately approved and tested rather than counted as numerical equivalence.

Scientific settings that must remain invariant

Hold constant the processed channel names/order/types/bads, montage and digitization, sampling frequency, average-reference projection state, forward solution and its source space/orientation, ad-hoc noise covariance, inverse operator instance, lambda2, inverse method="MNE", pick_ori="normal", MNE default parameters not intentionally version-locked, DK label identities and order, fsaverage_src, and label reduction mode="mean". No per-chunk covariance, inverse reconstruction, filtering, resampling, referencing, baseline correction, edge padding, rejection, or annotation-driven sample removal belongs in the equivalence change. Record MNE, NumPy, and backend versions because the project currently leaves MNE unpinned.

Final partial chunk semantics

For positive chunk size C samples and N > 0, the final interval is [kC, N) with length N-kC in 1..C. It is processed once with the same inverse and reduction settings and concatenated without padding, truncation, overlap, weighting, or special normalization. When N is divisible by C, do not create an empty terminal chunk. A recording shorter than C is one complete chunk and must equal the whole-Raw oracle. Empty Raw behavior should be explicit and tested at the implementation boundary rather than inferred scientifically.

Epochs non-regression criteria

The Raw option must not alter the Epochs branch. For the same Epochs fixture and environment, compare candidate with the clean baseline for: exactly one apply_inverse_epochs call; unchanged inverse arguments (lambda2, method="MNE", pick_ori="normal"); identical number/order of epochs, labels, and time samples; label arrays within the same strict tolerance; unchanged sfreq, tmin, channel/label order and locations, event_id, and generated event array; and the same exported filename/type. Exercise at least one normal event mapping and the existing fallback event path. Varying chunk_seconds must have no effect on any Epochs output or inverse call.

Material Alternatives

A looser rtol=1e-7 oracle would reduce backend-specific test fragility but could conceal an unintended setting or alignment change; it is not recommended without empirical justification. Bitwise equality is attractive but unnecessarily couples acceptance to backend/library implementation. Comparing exported .set files alone is also insufficient because serialization precision and event/annotation representation confound inverse equivalence.
