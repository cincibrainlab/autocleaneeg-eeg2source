Chosen Metadata Compatibility Semantics

The revised contract intentionally preserves the input Raw time base: output first_samp, meas_date, sample count, annotation descriptions/durations, annotation orig_time, and event onsets must match the attached source Raw. This is not a new relative-annotation API. The conversion path receives annotations already attached to the input Raw.

For attached annotations with orig_time=None, MNE has already included the source first_time in their stored onsets. Before attaching them to an output Raw with the same first_samp, the implementation subtracts first_samp / sfreq; MNE then applies that offset once, reproducing the original onsets without double shifting. For non-null orig_time, the output Info first receives the input meas_date, and the absolute annotations retain their origin/onsets without normalization. Tests use annotations actually attached to a source Raw, not fresh unattached annotations.
