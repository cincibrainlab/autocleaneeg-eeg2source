Senior Review Findings

  1. P1 — Annotation preservation is incorrect for real Raw annotation state and can either drop events or fail the conversion. _convert_raw_inverse_to_eeg passes raw.annotations into a new RawArray(first_samp=raw.first_samp), then _convert_raw_label_ts_to_eeg calls set_annotations. In MNE 1.6, annotations already attached to a Raw with nonzero first_samp are already re-referenced. Setting them again on another nonzero-first_samp Raw shifts them again. The independent MNE 1.6.0 probe produced source onset 2.1, then omitted that annotation entirely on the four-sample destination after the second shift. With non-null orig_time, the new output's meas_date=None caused RuntimeError: Ambiguous operation. The current test constructs a fresh unattached annotation at onset 0.1, so it validates the first shift rather than the actual copy path. This also changes the immutable legacy output contract: baseline output used first_samp=0 and no annotations, while Wave explicitly left any metadata extension pending Raven/PI decision. Action: obtain and document the metadata contract decision, then implement it deliberately. If preservation is approved, copy the required measurement-time metadata and normalize annotation time bases without reapplying the first-sample offset; add attached-source tests for orig_time=None and non-null orig_time. If strict 0.3.7 compatibility is required, retain first_samp=0 and absent annotations.
  2. P1 — Public constructor positional compatibility is broken. chunk_seconds was inserted before established positional parameters in ParallelProcessor, CachedProcessor, GPUProcessor, and RobustProcessor. A legacy call that passed n_jobs or recovery_mode positionally now binds that value to chunk_seconds and shifts every following argument. The focused test only uses keyword arguments/defaults and cannot catch this. Action: append the new parameter after the existing positional surface or introduce a separately reviewed keyword-only compatibility plan; add regression tests that instantiate every processor with the prior positional forms.
  3. P1 — Parallel and GPU Raw entry points do not use the new Raw chunk path despite accepting and receiving chunk_seconds. Both classes override process_file; ParallelProcessor.process_file reads Raw but unconditionally sends the object through the epochs-only _apply_inverse_parallel/apply_inverse_epochs and epochs conversion route, and GPUProcessor likewise remains epochs-oriented. The CLI now passes chunk_seconds to these modes, creating a false capability surface. No test exercises a Raw file through parallel, cached, GPU, or fallback processing. Action: either route Raw explicitly through the shared sequential chunk implementation or reject unsupported modes before processing; add processor-family Raw routing tests.
  4. P1 release blocker / P2 merge concern — Worker compatibility and version custody are unresolved. Defaults of one are conservative, and no BLAS/OpenMP global mutation was introduced. However, the previously supported explicit n_jobs=-1 is now rejected by constructors while the CLI still parses it as an integer; this is a breaking library/CLI contract rather than preserved legacy behavior. Separately, the distribution still reports 0.3.7 while exporting a new capability and changing defaults/validation/output metadata. The capability constant is useful for downstream detection but does not make a materially changed package safe to publish under the immutable 0.3.7 identity. Action: document and test a deliberate legacy sentinel policy (or a clearly versioned breaking change), and select/update package version consistently before any build or publication.
  5. P2 — Exception and resource proof remains narrower than the requested contract. The per-chunk finally releases the STC and calls manager cleanup, and the weak-reference tests are useful. But cleanup itself can mask the primary inverse/reduction exception, outer general process_file exceptions still do not perform the same owned-resource cleanup, and no bounded process RSS evidence exists. Compact label chunks are retained and duplicated at final concatenation; that may be acceptable for ROI-sized output but has not been measured. Action: preserve the primary exception if cleanup fails, add outer failure cleanup coverage, and run the previously specified bounded synthetic subprocess RSS smoke before release.
  6. P2 — The scientific and output compatibility suite is still mock-level. Half-open bounds are correct under MNE 1.6 (stop is the first sample not included), the final partial chunk is correct, immediate reduction and ordered concatenation are structurally sound, validation rejects the named invalid bounds, Epochs avoids the Raw method in the focused mock, and the 16 focused plus 5 robust tests pass. Missing are a real deterministic MNE inverse oracle, the Wave-requested full Epochs output/event regression, EEGLAB round trip, CLI subprocess, package build/install, processor-family Raw routes, attached annotation origins, and RSS. Action: close the P1 findings first, then add the smallest real integration checks necessary for the supported release surface.
